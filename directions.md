# SPEC & THREE DIRECTIONS PROPOSAL - TIKTOK DOWNLOADER (TIKWM ENGINE)

## Context & Spec
- **Target App:** TikSave (TikTok Video Downloader)
- **Engine Upgrade:** Migrasi dari RapidAPI ke TikWM Public API (endpoint `https://www.tikwm.com/api/`), gratis tanpa API key, support direct HD/1080p stream (`hdplay`), SD (`play`), dan audio MP3 (`music`).
- **Platform:** Web / Mobile Responsive (React + Tailwind CSS).

---

## 3 Pilihan Prototipe Desain (Huashu-Design)

### 1. Direction 1: Minimalist Modern Studio (`design-demos/dir-1.html`)
- **Konsep:** Clean, sleek dark-mode studio, modern typography (Plus Jakarta Sans).
- **Fokus:** Tampilan profesional dengan kontras tajam, input box lebar dengan gradient aksen Cyan-Rose, kartu preview video horizontal yang rapi.
- **Karakter:** Ringan, elegan, tidak melelahkan mata, fokus ke utilitas cepat.

### 2. Direction 2: Cyber / Neo-Brutalist Terminal (`design-demos/dir-2.html`)
- **Konsep:** High-tech utility tool, monospace font (Space Grotesk + Space Mono), border tegas, hard drop-shadows (cyan/pink).
- **Fokus:** Menampilkan sensasi raw stream extractor / power-user developer tool, teks status eksplisit (HD stream verified, engine tag, status 200).
- **Karakter:** Unik, bold, berbeda dari situs downloader pasaran, berkarakter kuat.

### 3. Direction 3: Mobile-First Glassmorphism Card (`design-demos/dir-3.html`)
- **Konsep:** Desain kartu ala aplikasi native mobile iOS/Android dengan efek blur subtle dan bottom navigation bar.
- **Fokus:** Sangat nyaman diakses lewat smartphone, tombol aksi satu jempol, kartu preview vertikal yang compact.
- **Karakter:** Akrab bagi pengguna TikTok di smartphone, responsif, modern.
